## 📜 About Me

I'm a **Full Stack Developer** who enjoys working across the entire application — from building interfaces users interact with to designing the backend systems that make them work.

Although I work comfortably with both frontend and backend technologies, **backend engineering is where my curiosity naturally pulls me**.

I enjoy understanding how things work beneath the abstraction, solving problems from first principles, and turning ideas into real, working systems.

I'm particularly interested in:

- 🧠 Problem solving and algorithms
- ⚙️ Backend architecture and API design
- 🗄️ Database design and data consistency

- ⚡ Concurrent and atomic operations
- 🌐 Real-time applications
- ☁️ Deployment and infrastructure
- 🧩 Learning how technologies actually work underneath

## 🧭 How I Learn

I don't like learning technologies just to add them to a stack.

My usual approach is:

```text
Understand the fundamentals
          ↓
       Experiment
          ↓
     Build with it
          ↓
     Break / Debug it
          ↓
 Understand what happened
          ↓
        Improve
```

The part I enjoy most is **going deeper**.

If something works, I want to know **why it works**.

If an algorithm solves a problem, I want to know **how it can be improved**.

If a technology abstracts something away, I want to understand **what is happening underneath it**.

That's usually where the most interesting learning happens.
